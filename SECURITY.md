# Security Policy

Frame Engine is an early-stage, solo-developed project (currently 0.1.0). It is
a tech demo, not production software, and it ships with no security guarantees.

## Supported versions

Only the latest release on `main` receives any fixes. Older tags are snapshots
and are not maintained.

| Version | Supported |
| ------- | --------- |
| latest  | yes       |
| older   | no        |

## Reporting a vulnerability

If you find a security issue, please report it privately rather than opening a
public issue. The preferred route is GitHub's private reporting:

1. Go to the **Security** tab of this repository.
2. Choose **Report a vulnerability** to open a private advisory.

As a solo project there is no guaranteed response time, but reports are read and
genuine issues will be addressed in a reasonable timeframe. Please give enough
detail to reproduce the problem.
